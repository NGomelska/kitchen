# Кухня — меню, покупки, рецепти

Особистий застосунок для родини: спільний список покупок з кількостями, меню з боулами і заготовками, книга рецептів.
Відкривається з іконки на телефоні (Samsung, Chrome), працює й без інтернету.

## Що вже є (v2, 17.10.2026)
- **Дизайн** «скетчбук + боул»: паперове тло, рукописні заголовки, кольори груп страв (білок, основа, овочі, соус, десерт, ціла страва). Світла й темна тема.
- **Меню-конструктор**: тиждень → день → тап на прийом їжі → вибір страв по групах → хто що їсть (Я / Т / С) → «Готово» або «Готово + на завтра». Кожен прийом їжі — миска з кольоровими сегментами.
- **Проста страва вручну**: назва + грами на порцію (варений рис 70 г) — без рецепта.
- **КБЖУ**: на порцію рецепта, на кожну миску і за день — окремо для кожного (порція тата ×1,3, сина ×0,5). Мета білку/ккал у «Ще».
- **Порахувати покупки**: усі миски тижня → список з кг і штуками; бакалія «є вдома» не відмічена.
- **Купити**, **Рецепти** (15 простих страв + 12 рецептів), **Ще** — як у v1.

Таблиця КБЖУ — `js/nutrition.js` (≈60 продуктів, на 100 г). Невідомий продукт → рецепт покаже «без даних для…», КБЖУ можна вписати вручну.

Спільні дані (Firebase), розбір рецептів Gemini і публікація на GitHub Pages — вже зроблені.

## Оновлення 24.10.2026 (зроблено)
1. **«Додати в меню» з рецепта** — кнопка в картці рецепта відкриває меню (день → прийом їжі), щоб поставити рецепт напряму, без пошуку через конструктор меню.
2. **Чек → покупки** (ідея Миколи) — «🧾 Фото чека» в «Купити»: Gemini читає чек, позиції зі списку стають купленими, решта йде в «Є вдома».

## Будова
- `index.html`, `styles.css` — сторінка
- `js/app.js` — екрани й кнопки
- `js/portions.js` — порції й кількості (скільки купувати)
- `js/nutrition.js` — КБЖУ
- `js/store.js` — де лежать дані (зараз локально; сюди ж додамо Firebase)
- `js/seed.js` — початкові дані (меню-миски, рецепти, список)
- `mockup.html`, `mock_shots/` — макет дизайну
- `manifest.webmanifest`, `sw.js`, `icons/` — іконка, встановлення, робота без інтернету
